# おさいふノート（PWA試作版 v2）

## v2で追加したこと
- 月間カレンダーで日ごとの収入・支出・差引を表示
- 日付をタップすると、その日付を設定した入力画面へ移動
- 管理タブから支出・収入カテゴリーを追加・削除
- 既存の記録・予算・固定費を保持するため、保存キーは旧版と同じ

## 公開方法
GitHub Pages のリポジトリ直下（root）に `index.html`、`manifest.webmanifest`、`sw.js` を置き、コミットしてください。Pages は main / (root) の設定を使います。

## 注意
データは端末のブラウザ内（localStorage）に保存されます。更新時に同じGitHub Pages URLを使えば、通常は同じ保存領域を引き継ぎますが、更新前にアプリの「管理」からJSONバックアップを書き出してください。Webサイトデータ消去などで消える可能性があるため、バックアップは定期的に保存してください。銀行・カードとの自動連携や自動クラウド同期はありません。
