# おさいふノート v4

GitHub Pagesで公開するスマートフォン向け家計簿PWAです。

## v4の更新点
- 登録済みの収入・支出を編集・削除
- カテゴリーごとの色設定
- 月間支出の円グラフ
- 支払い方法の追加・編集・削除
- 既存のカレンダー、月間集計、固定費管理、バックアップ機能

## 公開
このフォルダ内の `index.html`、`manifest.webmanifest`、`sw.js` をGitHubリポジトリのルートにアップロードして置き換えてください。

## データについて
v4は新しい保存領域キーを使うため、以前のバージョンの記録は引き継ぎません。記録は利用中のブラウザ内に保存され、銀行口座とは自動連携しません。
