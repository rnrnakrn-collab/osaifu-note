# おさいふノート（PWA試作版）

## できること
- 収入・支出の記録、カテゴリー別集計、月別収支
- 税込・税抜・非課税、税抜入力時の8%/10%計算
- 楽天カード利用日の支出計上と翌月27日の引き落とし予定日入力
- 三菱UFJデビットの即時決済としての記録
- 固定費・サブスクの登録、予算管理
- JSONバックアップと復元
- ホーム画面追加に対応するPWA構成

## 公開方法
PWAとしてホーム画面追加するにはHTTPSで公開する必要があります。GitHub Pages等にこのフォルダの内容を配置し、公開URLをiPhoneのSafariで開いて「共有」→「ホーム画面に追加」を選びます。

## 大切な注意
- 現状はブラウザのlocalStorageに保存します。SafariのWebサイトデータ削除などで消える可能性があるため、定期的に「バックアップを書き出す」を使ってください。
- JSONバックアップをiCloud Drive等に保存し、新しい端末で「バックアップから復元」できます。
- 銀行口座・カード会社との自動連携、実際の請求額の自動取得はありません。
- 楽天カードの通常の締め日・支払日を初期値として扱いますが、利用先・金融機関休業日等で実際の請求/引落しは異なる場合があります。明細・カード会社の確定情報を優先してください。
- 税抜金額に税率を掛けて円単位に四捨五入します。実際のレシートの端数処理と異なる場合があるため、レシートの税込合計を記録する場合は「税込」を選んでください。
- これは試作版であり、正式な金融サービスではありません。
